# FocusInk BH

A static Pomodoro study website for the GS 6203 Business Project.

Live site target after GitHub Pages is enabled:

https://0xAli1.github.io/focusink-bh/

## Features

- Pomodoro, Short Break, and Long Break timers
- Start, pause, reset, skip, and complete controls
- Task input before each focus session
- Ink Progress Map for visible study progress
- Session stats and downloadable focus report
